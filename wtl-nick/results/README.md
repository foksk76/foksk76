# Результаты проверки гипотезы №1

Здесь сохраняются только воспроизводимые результаты, построенные на данных из `../data/`.

## Рекомендуемые файлы

- `baseline.md` — описание исходной версии скилла и выборки;
- `sample-060.md` — предварительный анализ после 60 найденных ников;
- `sample-100.md` — основной анализ после 100 проверенных ников;
- `generated-vs-real.csv` — сравнение реальных и сгенерированных ников;
- `rejected-cases.md` — реальные ники, ошибочно отсекаемые скиллом;
- `methodology-changes.md` — предложения для Hypothesis 2, не меняющие Hypothesis 1 задним числом.

## Обязательные сведения в каждом отчёте

1. Версия гипотезы и commit SHA.
2. Дата выгрузки данных.
3. Размер исходной и очищенной выборок.
4. Использованные источники.
5. Правила дедупликации.
6. Количество записей по уровню уверенности.
7. Порог гиперактивности и список исключённых из конкретного сравнения ников.
8. Ограничения и неопределённость.
9. Вывод: подтверждена, частично подтверждена, не подтверждена или данных недостаточно.

Не публиковать статистические выводы по приблизительным или незавершённым данным.
