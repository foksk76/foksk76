# Данные исследования

Каталог содержит только проверяемые данные из открытых источников.

## Файлы

- `wtl-nicks.csv` — одна строка на подтверждённый ник игрока или персонажа WTL.
- `sources.csv` — журнал канонических URL и поисковых запросов.
- `decisions.csv` — решения по включению, исключению и дедупликации записей.

## Правила

- Не добавлять приблизительные числа.
- Не заменять отсутствующие данные нулём.
- Не считать языковые копии одной страницы отдельными источниками.
- Не сохранять персональные данные, не нужные для исследования.
- Для основной статистики использовать только записи с `confidence=high` или явно оговорённую подвыборку `medium`.
- Любое число страниц является подтверждённой нижней границей.

## Статусы

`record_status`:

- `candidate` — найдено, ожидает проверки;
- `verified` — связь с WTL подтверждена;
- `excluded` — исключено с указанием причины;
- `duplicate` — дубликат другой записи.

`confidence`:

- `high`;
- `medium`;
- `low`.
