# WTL Nick — Hypothesis 1

Облачный рабочий каркас для проверки гипотезы №1 о подборе игровых ников для **Will To Live Online**.

## Цель

Проверить, насколько правила `wtl-nick/SKILL.md` соответствуют реальным моделям именования игроков WTL и позволяют создавать читаемые, запоминающиеся и относительно редкие ники.

## Основной принцип

Все выводы строятся на подтверждённых данных из открытых источников.

Приоритет источников:

1. реальные игроки и персонажи Will To Live Online;
2. публичные кланы WTL, включая клан «Распад»;
3. Steam Community, руководства, обсуждения и скриншоты WTL;
4. видеоматериалы, где ник виден в интерфейсе WTL;
5. другие игры и общие источники — только как отдельная контрольная группа.

## Статус

- Гипотеза: №1.
- Скилл: проверяемая версия, не окончательная истина.
- Источники: только открытые и проверяемые.
- Основная единица исследования: подтверждённый ник реального игрока или персонажа WTL.
- Число найденных страниц считается нижней границей, а не полной частотой упоминаний.

## Порядок работы

1. Зафиксировать версию скилла.
2. Собирать реальные ники WTL с каноническими URL.
3. Дедуплицировать страницы и владельцев.
4. Оценивать ники по скиллу без показателя упоминаемости.
5. Отдельно измерять активность владельца и распространённость ника.
6. Применять фильтр гиперактивности только к статистическому сравнению.
7. Публиковать промежуточные результаты в `results/`.
8. Изменения правил оформлять новой версией гипотезы, не подгоняя текущую версию под результаты.

## Ограничения публикации

Не сохранять персональные данные игроков, кроме публичного игрового ника, публичной клановой принадлежности и ссылок, непосредственно подтверждающих связь с WTL.
