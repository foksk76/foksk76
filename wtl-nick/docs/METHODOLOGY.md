# Методика исследования

## 1. Единица наблюдения

Основная запись — подтверждённый публичный ник реального игрока или персонажа Will To Live Online.

Связь с WTL должна подтверждаться открытым источником:

- профилем или обсуждением Steam;
- руководством WTL;
- клановой страницей;
- видео или скриншотом с интерфейсом игры;
- иным источником с явным указанием WTL.

## 2. Достоверность

Для каждой записи хранить:

- точный ник;
- канонический URL;
- дату проверки;
- тип источника;
- тип подтверждения;
- класс и клан, если указаны явно;
- уровень уверенности;
- примечание о неоднозначности.

Не угадывать класс, владельца, транслитерацию или принадлежность к клану.

## 3. Дедупликация

Одной страницей считать один канонический материал.

Не считать отдельными страницами:

- языковые версии Steam;
- URL с разными параметрами локализации;
- зеркала;
- повторные публикации одного материала;
- фрагменты одной страницы.

Один владелец с десятью страницами остаётся одной независимой сущностью.

## 4. Разделение метрик

### Активность владельца

`F_confirmed` — количество подтверждённых уникальных WTL-страниц одного владельца.

Используется только для анализа публичной активности.

### Распространённость ника

`E_independent` — количество независимых сущностей с точным ником:

- разных игроков;
- брендов;
- организаций;
- персонажей;
- игровых объектов;
- произведений.

Это основная метрика риска совпадения.

### Фильтр гиперактивности

`H = mean(F_confirmed) + 0.45 × σ(F_confirmed)`

Записи выше H исключаются только из статистического сравнения качества ника с числом страниц.

В формулу включать только точные значения. Приблизительные числа и строки `нет данных` запрещены.

## 5. Оценка скиллом

Оценивать ник без критерия упоминаемости.

| Критерий | Максимум |
|---|---:|
| Фонетика и читаемость | 20 |
| Запоминаемость | 15 |
| Соответствие жанру | 15 |
| Соответствие классу | 15 |
| Соответствие клановой системе | 10 |
| Оригинальность формы | 15 |
| Отсутствие отрицательных ассоциаций | 10 |

Если критерий невозможно оценить, не ставить ноль — исключить его из знаменателя и нормировать результат.

## 6. Правила поиска

Для каждого ника использовать одинаковый набор запросов:

1. `"НИК" "Will To Live Online"`
2. `"НИК" WTLO`
3. `site:steamcommunity.com "НИК" "Will To Live Online"`
4. `site:clanraspad.ru "НИК"`
5. `"НИК" game player character clan`
6. `"НИК" игра игрок персонаж клан`

Фиксировать только реально открытые и проверенные страницы.

## 7. Уровни уверенности

- **Высокий** — ник виден в интерфейсе WTL или явно назван персонажем/игроком WTL.
- **Средний** — автор публикует WTL-контент, но не доказано, что ник совпадает с именем персонажа.
- **Низкий** — связь косвенная; такие записи не входят в основную статистику.

## 8. Контрольные группы

- `WTL-real` — реальные подтверждённые ники WTL.
- `Skill-generated` — ники, созданные зафиксированным скиллом.
- `Control` — ники других MMORPG или нейтральная выборка.

Источники и правила сбора для каждой группы документировать отдельно.

## 9. Статистические ограничения

Не рассчитывать среднее, σ, корреляцию или пороги, если:

- протокол поиска различался между никами;
- есть приблизительные значения;
- отсутствующие данные заменены нулём;
- дедупликация не завершена;
- не сохранён список URL;
- выборка слишком мала для заявленного вывода.

Любое число упоминаний обозначать как подтверждённую нижнюю границу, а не полный охват интернета.

## 10. Версионирование гипотез

- `Hypothesis 1 / v1` не менять во время основного набора данных.
- Замечания к правилам фиксировать отдельно.
- Исправления методики, влияющие на результат, оформлять новой версией.
- Сырые данные не переписывать без журнала решения.
